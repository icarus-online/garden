# THE GARDEN - RESEARCH DESIGN HISTORY

## v0.1 / Original concept

- Invented the garden/terroir/atmosphere framing with a free-standing, non-prescriptive art file.
- Built an atmospheric, interactive HTML experience with fragments inspired by Bourdain, Shulgin, Watts, Weil, Heraclitus and Marcus Aurelius.
- The original visual site juxtaposed no-file, neutral text, explicit persona, and Garden; this was a concept comparison, not a controlled factorial study.

## v0.2 / Scientific protocol draft

- Added a stricter 2x2: neutral versus Garden, crossed with cross-session memory off/on.
- Added fresh-session withdrawal, transfer, leakage controls, blinded annotation, preregistration and reproducibility recommendations.
- No experiment was run; no statistical outcomes exist.

## v0.3 / Icarus Online LLC independent research consolidation

- Corrected project identity and independent ownership. Soberlink remains a historical harness mention, not the owner or testbed.
- Preserved previous concept and protocol in `archive/`.
- Integrated the original art-oriented HTML with an expanded origin story, two-room art/lab principle, actual 2x2 factorial arms, withdrawal stages, a hypothetical-outcome interpreter, and interactive seeded randomization.
- Published researcher-oriented charter, context reconstruction, literature map, ethics/IP boundary, pilot runbook, coding rubric, preregistration draft and public note.
- Added standard-library Python allocation script, byte manifest, JSON schema, and tested identical JS/Python randomization.
- Did not include the supplied private audio recording in the shareable package.

Next gate: freeze authorized model, task bank, neutral corpus token matching, memory adapter, and blind coding before a feasibility pilot.
