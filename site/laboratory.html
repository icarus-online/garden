What a complete research trace must contain

Exact task and assembled context hashes; pinned model, provider, version, reasoning and sampling configuration; memory reads and writes; timestamp and session identifiers; tool permissions; outputs and errors; deviations and exclusions. Condition assignments must remain outside blinded reviewer artifacts. The current schema supports diagnostic records with no empirical outputs; a validated live trace contract and provider adapter remain pilot prerequisites.
